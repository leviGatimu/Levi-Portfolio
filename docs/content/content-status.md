## Screenshot capture checklist (for Levi)

1. Clean data (no test accounts named "wixytester"), no dev overlays, no personal info visible.
2. Desktop/web: 1440×900 window at 2× device pixel ratio → 2880×1800 PNG. Crop to 16:10 in the admin if needed.
3. Mobile screens: native device screenshot, exported as PNG; use `4:5` cover aspect.
4. Hardware/robotics: real photos, landscape, daylight, uncluttered background; 4:3.
5. Export PNG for UI (lossless), JPEG q85 for photos. ≤ 5 MB per file (admin limit); `next/image` handles delivery formats.
6. Write alt text as you upload — describe what the screen shows and why it matters.
